# API Contract (v1, first milestone)
Source of truth for schemas: `backend/models.py` (Pydantic). Update this file in the same change as any API change.

**Status legend:** ✅ implemented (tested) · 🕓 planned (does NOT exist yet; calling it returns 404/405).

## Conventions
- **Units (SI, always, in every field):** mass `kg`; radius and position `m`; velocity `m/s`; simulation time `s`; G = `6.67430e-11 m^3 kg^-1 s^-2`. Unit is in the field name suffix (`massKg`, `radiusM`, `positionM`, `velocityMPerS`, `simulationTimeS`).
- **Coordinates:** one fixed, right-handed Cartesian frame (x × y = z). Positions and velocities share this frame. The origin is the simulation origin (not tied to any body). The frontend may scale/offset *rendered* distances for visualization but must never alter or send scaled values as API physics values.
- **Numbers:** JSON numbers, finite only. NaN/Infinity (and overflow such as `1e999`) are rejected.
- **IDs:** generated by the backend (`body-<12 hex>`), unique, never reused, stable across reads. Clients must not send `id`.
- **Colors:** `#RRGGBB` (6 hex digits, case-insensitive; stored as sent).
- **Unknown request fields are rejected** (422).
- **Validation errors:** HTTP 422, body `{"detail": [{"loc": ["body","massKg"], "msg": "...", "type": "greater_than"}]}`.
- **Base path:** backend serves `/api/v1/...` itself. Note: the Vite dev proxy currently *strips* `/api` (see Known issues).

### Body
```json
{"id":"body-3f9a1c2b7d4e","name":"Earth","massKg":5.972e24,"radiusM":6.371e6,
 "positionM":{"x":1.496e11,"y":0.0,"z":0.0},"velocityMPerS":{"x":0.0,"y":29780.0,"z":0.0},"colorHex":"#3b82f6"}
```
`name`: 1–64 chars. `massKg`, `radiusM`: finite, `> 0`.

### SimulationState
`{"status": "paused" | "running", "simulationTimeS": number, "bodies": [Body]}` — bodies in creation order.

## Endpoints

### ✅ `GET /healthz`
Liveness probe. (Legacy `GET /health` still exists with the same response.) No body.
Response 200: `{"status":"ok"}`. Errors: none.

### ✅ `GET /api/v1/simulation/state`
Authoritative snapshot (D-001). No body. Response 200 (fresh server):
```json
{"status":"paused","simulationTimeS":0.0,"bodies":[]}
```
Errors: none expected.

### ✅ `POST /api/v1/bodies`
Add a body. Request: Body without `id`. Response **201**: the full Body including generated `id`.
```json
// request
{"name":"Earth","massKg":5.972e24,"radiusM":6.371e6,"positionM":{"x":1.496e11,"y":0,"z":0},"velocityMPerS":{"x":0,"y":29780,"z":0},"colorHex":"#3b82f6"}
// response 201: same plus "id":"body-3f9a1c2b7d4e"
```
Errors: 422 for `massKg`/`radiusM` ≤ 0 or non-finite, non-finite vector component, bad `colorHex`, empty/too-long `name`, missing field, unknown field (including `id`).
Example 422: `{"detail":[{"loc":["body","massKg"],"msg":"Input should be greater than 0","type":"greater_than"}]}`

### 🕓 `PATCH /api/v1/bodies/{body_id}` — planned
Partially update a body (same field rules; `id` immutable). Response 200 Body. Errors: 404 unknown id, 422 validation. Example: `{"massKg":7.3e22}`.

### 🕓 `DELETE /api/v1/bodies/{body_id}` — planned
Remove a body. Response 204, no body. Errors: 404 unknown id.

### 🕓 `POST /api/v1/simulation/start` — planned
Set status `running`. Response 200 SimulationState. Needs physics engine (D-003 pending).

### 🕓 `POST /api/v1/simulation/pause` — planned
Set status `paused`. Response 200 SimulationState.

### 🕓 `POST /api/v1/simulation/step` — planned
Request `{"dtS": 3600.0}` (finite, > 0). Advance by `dtS` seconds. Response 200 SimulationState plus events. Errors: 422 bad `dtS`, 409 if running.

### 🕓 `POST /api/v1/simulation/reset` — planned
Clear bodies, time 0, status paused. Response 200 SimulationState. (Distinct from the test-only store override; tests never use a public reset.)

### 🕓 `GET /api/v1/events` — planned
List simulation events (e.g. collision/merger). Response 200 `{"events":[{"id":"evt-1","type":"merger","simulationTimeS":123.0,"bodyIds":["body-a","body-b"],"resultBodyId":"body-c"}]}`. Event schema is a proposal pending M0 results.

### 🕓 Checkpoints — planned follow-up
Save/restore endpoints are not specified. REBOUND checkpointing was evaluated in M0 (provisional) but the architecture does not yet support it.

## Assumptions / known issues
- Initial `status` is `paused`; `running`/time advance arrive with start/step (no physics yet).
- State is in-memory, single process, lost on restart.
- **Vite proxy mismatch:** `frontend/vite.config.ts` strips `/api`, so a browser call to `/api/api/v1/...` is needed or the rewrite must be removed (which breaks `App.tsx`'s `/api/health`). Decision needed from the frontend owner; not changed here.
- Mass/radius have no upper bound beyond "finite".
- Body overlap/collisions are not checked on creation.
